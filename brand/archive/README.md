# Archived brand geometry

`monogram.mjs` generates the **folded-ribbon** monogram — a strip of card folded once, read as
the letter V. It was generated by us; it is not the operator's logo, and it has no leaf. It was
replaced by a trace of the real mark (see `assets/brand/velora-mark.svg`) after the brand
decision on 2026-11-21.

Nothing references this file. It is kept so the earlier commits stay readable, not as a source.
